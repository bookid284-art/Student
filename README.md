# 里屋

许知夏是住宿的高三学生。单亲的母亲许桂芳每天打电话追问成绩，成绩不好时电话那头不再像问句，手机可以被锁，宿舍里装着摄像头。同学嘲笑面貌和精神状态，嘲笑分数，威逼请客，孤立，不愿意同桌。班主任梁老师觉得这个学生聪明，却恨铁不成钢。

压力大到一个程度，恶意在另一间屋里变成能走过来的东西。整场没有战斗。耳塞、镜头布、汽水和那点没灭的光只能用来周旋、躲开、把人引开。校医室退休的周先生把两扇门说完。一扇要用手拨开，带着那点光离开。一扇从柜子里面带上，人就留在这间屋里。

主线只是这条走廊。要走完它，还得把别人写下来的东西读完，再把不属于这间屋的三样旧物送回去。这些不是可跳过的收集。空位、办公室、校医室和周先生的第二段话都认它们。

按读完、来回躲、再读完的走法，一轮落在三到四个小时以内。只冲文字、不看句子，会短不少。这里没有 Unreal 编辑器，这个时长没有在 Play 里计过时。

## 必经的支线

- 宿管老吴的三页值班记录在南边值班室。读完才能拿抽屉里的镜头布。他不替你盖镜头。
- 江晚的四张条子散在空位旁、走廊、小卖部柜台和储物柜。她曾经想同桌，后来没有。凑齐再坐下。这不是一段恋爱。
- 宿舍铁盒里的硬币只负责打开小卖部。请客的账本要钉到走廊布告栏上。硬币不是再请一轮。
- 梁老师的字条打开年级组，不打开校医室。里面有孙老师、页边和家委会三页记录，再往北的长廊上有四张告示。看完，校医室才开。
- 周先生先不说两扇门。林小满已经毕业，人不住在这里。铅笔盒、过期月票和课表要放到托盘上，他才把两扇门说完。送回去不是把她救出来。
- 三篇自己的作文可以放在光里的长凳上。放了，离开的结尾会多一句。不放也能离开，也能留下。作文不是门票。

小卖部还有第二瓶汽水。校医室有一节备用电池。电量撑的是那点用来后退的光，不是结局里的那一点。

## 怎么玩

用已经装好的 Unreal Engine 5.7 打开 `Student.uproject`，直接 Play。里屋搭在示例关卡上方，不需要再摆关卡，也不要另外下载资源。

- WASD 移动，鼠标环顾
- Shift 跑，Ctrl 蹲
- E 交互，F 点亮那点没灭的光，Q 合上正在看的文字
- 结局画面按 R 再走一遍

光能让没有脸的同学退后，蹲下能让他们看丢，汽水能引开大约十八秒。这些都不造成伤害。心神被压满也到不了结局，只会让人更想找一个没有声音的柜子。耳塞让他们更难看清你，但拨开关之前必须回床上拿下来。镜头布只能盖宿舍那一只。

## 结局

| 做法 | 条件 | 留下的问题 |
| --- | --- | --- |
| 离开 | 听周先生把两扇门说完，在空位上坐过，把试卷交到办公室门口，没戴耳塞，用手拨开光里的开关 | 走出去以后，母亲、老师和那个班都还在。光没有删除他们 |
| 锁上 | 听周先生把两扇门说完，从柜子里面把门带上 | 安静是真的。明天那张还没交的卷子也一起被留下了 |

走到第二段话之前，值班记录、四张条子、钉上的账、三页会议、四张告示和三样旧物都要做完。心神满了也不会另外出现结局。

## 资源和代码

- 房间用引擎自带的方块、球体、圆柱搭成
- 裂开的镜子和试卷是运行时画的，不画一张可怖的脸
- 没有脸的同学用项目里已有的 Mannequin
- 中文使用随仓库附带的 Droid Sans Fallback（Apache 2.0，见 `Content/NightSchool/Fonts/`）
- 玩法代码在 `Source/Student/NightSchool/`
- 原有的第一人称移动和 `UStudentInteractionComponent` 仍被这场幻觉使用

进入 Play 之后，GameInstance 会自己开始。示例关卡原来的 GameMode 不用改。
